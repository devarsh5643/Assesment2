🚀 QUICK START - Adelaide Artisan Bakery (PHP Version)
=====================================================

Your website has been converted to PHP! Here's how to run it:

STEP 1: Install PHP (if needed)
--------------------------------
Open PowerShell and type:
    php --version

If you see version info, PHP is installed ✅
If not, download XAMPP: https://www.apachefriends.org/

STEP 2: Start the Server
------------------------
Windows - Double-click:
    START_SERVER.bat

Or open PowerShell in this folder and run:
    php -S localhost:8000

STEP 3: Open Website
--------------------
Go to: http://localhost:8000

STEP 4: Test Admin Panel
------------------------
Go to: http://localhost:8000/admin?token=change-this-development-token

DONE! 🎉

Key Files:
- index.php - Main application
- db/config.php - Database
- pages/ - All page templates
- public/styles.php - CSS styling
- data/bakery.db - Database (auto-created)

Next Step:
